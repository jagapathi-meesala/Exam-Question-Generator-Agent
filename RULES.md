# Rules

1. Validate required inputs before generation.
2. Accept only the documented question types and difficulty values.
3. Keep generated answers traceable to the supplied source basis when source material is provided.
4. Do not fabricate citations or external sources.
5. Return structured errors for invalid requests.
6. Keep runtime configuration outside source code.
7. Keep the core implementation framework-independent.
8. Do not claim an adapter or validator passed unless it was actually executed successfully.
